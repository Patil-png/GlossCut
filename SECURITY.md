# Security Policy

## Supported Versions

We actively provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**DO NOT open a public Issue for security vulnerabilities.**

If you discover a security vulnerability within this project, please report it privately.

### Reporting Process
1. Email your findings to the CTO/Lead Developer.
2. Include a detailed description of the vulnerability.
3. Provide steps to reproduce the issue (PoC).
4. Allow up to 1 week for an initial response.

We follow a responsible disclosure policy and will coordinate a fix before making the vulnerability public.
